Demostración JWT con Javalin 7

Proyecto educativo - PUCMM ECT

1. Autenticación (Login)

Envía credenciales al endpoint POST /login para obtener un token JWT.

2. Consultar Estudiantes (JWT)

Llama al endpoint protegido GET /api/estudiante usando el token JWT obtenido.

Header enviado: Authorization: Bearer <token>

3. Acceso con Token Personalizado (X-Mi-Token)

Llama al endpoint GET /api-token/info usando un header personalizado.

Header enviado: X-Mi-Token: <valor>

4. Log de Peticiones

Historial de las peticiones HTTP realizadas desde esta página.
